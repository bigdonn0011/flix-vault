# 🎬 Flix-Vault

A high-performance, mobile-first cinema discovery web application engineered to browse, search, and track your favorite movies and series via a responsive, native-feeling architecture.

---

### 🚀 Tech Stack

* **Framework:** **Next.js** (App Router) for hybrid static/server rendering and optimized routing.
* **Language:** **TypeScript** for strict type safety, predictable API data contracts, and clean code scaling.
* **Styling:** **Tailwind CSS** for a utility-first, modern dark-mode system built on hardware-accelerated layouts.
* **Hosting:** Optimized for zero-config global edge deployment on **Vercel**.

---

### 📱 Key Architecture Features

* **Mobile-First Geometry:** Deeply optimized viewport geometry using CSS Grid configurations and snapping mechanics for fluid mobile scrolling.
* **Dynamic Media Matrix:** Utilizes Next.js dynamic routing to instantly generate high-performance content cards and descriptive detail views.
* **Production Typography:** Implements `next/font` optimization to automatically inject high-performance font rendering across all layouts.
* **Resource Directory Setup:** Configured to load local visual assets strictly out of the unified `/public/img/` pathway to avoid broken relative links.
